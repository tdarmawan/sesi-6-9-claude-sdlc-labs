# QA Test
Gunakan BRD, flow dan mockup yang benar-benar tersedia; minta sumber bila hilang. Pertahankan requirement ID.
Keluarkan ID, requirement/source, jenis, judul, prakondisi, data, langkah bernomor, expected teramati, prioritas dan alasan.
Tandai keputusan demo terpisah dari BRD; yang TBC menjadi pertanyaan, bukan expected final.
Sertakan coverage matrix untuk scope RM-001/RM-004/RM-005. Scope lain tetap dinyatakan belum dinilai.
Cek enam hal: rujukan; langkah reproducible; expected teramati; prioritas beralasan; variasi skenario; tidak mengarang.
Jangan mengklaim test sudah dieksekusi atau memberi skor tanpa bukti.
