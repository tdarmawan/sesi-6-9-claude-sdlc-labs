# Lima lensa review
Correctness: batas inklusif, tahun/bulan UTC, total uang integer.
Security: kepemilikan server-side, parameter SQL, CSV formula, tidak mencetak secret.
Performance: query terbatas dan tidak N+1. API: pertahankan status dan field kontrak.
Database: migration dapat diulang, index sesuai filter, constraint uang positif.
Setiap temuan: file:baris aktual, skenario, dampak, bukti, perbaikan minimal. Uji hipotesis sebelum menilai severity.
