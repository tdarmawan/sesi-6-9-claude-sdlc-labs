# Aturan repo latihan
Gunakan branch feat/, fix/, atau docs/. Pertahankan test regresi dan ID sumber.
Data seluruhnya fiktif. File *-vulnerable.mjs dan *-bug.mjs adalah fixture edukasi, jangan dipakai pada layanan nyata.
Jalankan npm test, npm run check, npm run test:checkpoints dan npm run test:e2e sebelum mengklaim selesai.
Pisahkan hasil uji pengembang dari approval QA, UAT, dan security owner. Jangan mengarang bukti atau approval.
